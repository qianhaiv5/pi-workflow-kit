# 文档治理台账

> **用途**：`docs/文档治理规范.md` 的**数字面与词表面**。规范保持跨项目可复用（不写本项目基线），基线在这里。
> **机器可读**：判据 1 / 2 / 6 直接读本文件的 `禁词:` / `软禁词:` 两行。缺行或值为空 ⇒ 判据脚本必须报错（禁止空正则匹配一切）。
> **维护**：只降不升；每次治理批次完成后同批回写。数字会腐烂，模式不会。

禁词: 批[ -]?[A-Z]|第[0-9一二三四五六七八九十]+轮|轮次|勘误|本轮|本次改动|phase[ -]?[0-9]|Step[ -]?[0-9]
软禁词: 阶段[ 0-9]|v[0-9]+\.[0-9]+

## 四 · 复算命令

```bash
BAN=$(sed -n 's/^禁词: //p' .pi/designs/文档治理台账.md)
[ -n "$BAN" ] || { echo "缺台账或禁词行为空"; exit 2; }
grep -rnE "$BAN" docs --include='*.md' | grep -v '^docs/历史/' | wc -l          # 判据 1
find docs -name '*.md' -not -path 'docs/历史/*' | grep -cE 'V[0-9]+|20[0-9]{2}-[0-9]{2}'   # 判据 3
find docs -name '*.md' -not -path 'docs/历史/*' -exec wc -l {} + | awk '$1>250 && $2!="total"' | wc -l  # 判据 4
grep -rnE '[A-Za-z]:[\\/](Users|Program Files|npm-global)' docs --include='*.md' | grep -v '^docs/历史/' | wc -l  # 判据 5
```

- 判绿只看**命中行**，不看 `grep` 退出码（0 命中时 grep 返回 1）。
- 基线只降不升。
