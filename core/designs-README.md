## 🛠 维护规则

1. 新增报告 ⇒ 在对应分组表**追加一行**（文件名 + 一句话 + 状态/提交号）；不得复述正文。
2. 状态标记：`✅ 已完成 <短提交号>` / `🔄 进行中` / `⚠️ 已被 <文件> 取代`。
3. 计数漂移自检（应输出空）：
   ```bash
   comm -23 <(ls .pi/designs/*.md | xargs -n1 basename | sort) <(grep -o '`[^`]*\.md`' .pi/designs/README.md | tr -d '`' | sort -u)
   ```
4. 只做指针：正文变更**只改正文那份**，本页不复制。
